- resonance chambers
- marketing vibration features


Only classify BC when supported by:

- manufacturer specifications
- official technical documentation
- reliable technical sources


If a product uses unclear wording:

Examples:

- vibration unit
- vibration driver
- low frequency vibration module
- enhanced bass vibration

You MUST verify whether it is:

A) A true bone conduction audio driver

OR

B) A non-audio vibration/haptic system


Only option A counts as BC.
