FIELD AUDIT & REPAIR RULES
==================================================
1. driver_config & driver_type Consistency:
   - driver_config MUST NOT have spaces around "+" (e.g., fix "1DD + 1BA" -> "1DD+1BA").
   - Allowed driver_type: DD, BA, BC, Planar, Hybrid, Tribrid, EST, MEMS, PZT.
   - Single Technology Rule: Any quantity of a single driver type is NOT a Hybrid (e.g., "2DD" -> "DD", "4BA" -> "BA", "2Planar" -> "Planar").
   - Hybrid: Exactly 2 distinct driver technologies (e.g., "1DD+1BA", "1DD+1BC", "2DD+4BA").
   - Tribrid: 3 or more distinct driver technologies (e.g., "1DD+4BA+2EST", "1DD+2BA+1BC").
   - Secondary Driver Check: Verify if bone conduction (BC), PZT, or EST drivers exist before approving.

2. Form Factor & Connector Matrix:
   - Allowed form_factor: "IEM", "Wireless Earbuds (TWS)", "Earbuds (Wired)", "Wireless Over-Ear Headphones", "Over-Ear Headphones (Wired)".
   - Allowed connector: "Bluetooth", "2-pin", "QDC", "MMCX", "A2DC", "Fixed Cable", "Detachable Cable", "Proprietary", "Electrostatic".
   - Hard Matrix Rules:
     * "Wireless Earbuds (TWS)" & "Wireless Over-Ear Headphones" MUST use "Bluetooth".
     * "IEM" & "Earbuds (Wired)" CANNOT use "Bluetooth", "Detachable Cable", or "Electrostatic". They MUST use shell sockets ("2-pin", "MMCX", "QDC", "A2DC"), "Fixed Cable", or "Proprietary".
     * "Over-Ear Headphones (Wired)" CANNOT use "Bluetooth".
     * IEMs with EST tweeters use "2-pin" or "MMCX", NEVER "Electrostatic".
     * "Proprietary" is only for manufacturer-specific sockets with NO standard replacement-cable compatibility (e.g., Brise Audio Fugaku, Etymotic ERX/EVO, Madoo Type 512/711, Noble XM1, Phonak PFE 232, Sleek SA6, PSB M4U 4).

==================================================

  * Midrange scooped relative to bass & treble → Verify "V-Shaped" / "U-Shaped" (reject "Neutral")
- Align the tags strictly to the physical acoustic measurements.
